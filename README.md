# 复盘终端 · 每日更新的股票复盘 PWA

移动端股票复盘工具，五个页面：消息面、题材轮动、大数据（龙虎榜）、连板梯队、会员中心。
每个交易日收盘后由服务端定时抓取真实行情写入站点，手机浏览器打开即为最新交易日数据，
可「添加到主屏幕」当 App 使用，断网仍能打开上一次缓存。

## 快速开始

```bash
python3 -m pip install requests
python3 scripts/market_update.py          # 抓取最近已收盘交易日并写入 app/
python3 -m http.server 8000 -d app        # 本地预览（PWA 安装需 HTTPS，线上部署见下）
```

部署到服务器、配置 systemd timer / cron、Nginx + HTTPS、口令保护、回滚与告警：
见 [`deploy/README.md`](deploy/README.md)。

## 数据来源与口径

- 落地页与交互：消息面 → 点开看摘要与原文链接；题材轮动 → 点题材看当日涨停成分股（按连板数 / 按涨停时间切换，点个股看细节）；连板梯队 → 点任意一行看个股细节。
- 消息面：财联社电报（`/v1/roll/get_roll_list`，需先取首页 `acw_tc` cookie 并签名）、中国政府网要闻（`YAOWENLIEBIAO.json`）、国家发展改革委新闻发布（列表页）。按来源权威度与政策关键词打分排序，官方与财联社均衡取 12 条，标题自动打题材标签。抓取失败时降级为收盘速览，不阻断行情更新。
- 题材板块与涨停成分股：同花顺 `limit_up/block_top`，提供板块涨跌幅、当日涨停股、首封时间、几日几板、涨停原因。
- 个股涨停细节：同花顺 `limit_up/limit_up_pool`（涨停类型、涨停原因、开板次数、封单额、换手率、流通市值）。
- 个股开高低收 / 成交额 / 市值：腾讯 `qt.gtimg.cn` 收盘快照，只对最新交易日有效。
- 指数日线、涨停池家数、龙虎榜明细：东方财富公开接口。
- 龙虎榜净买入 = 买入额 − 卖出额，按个股去重，单位亿元。
- 连板状态取涨停池 `lbc`，`zbc > 0` 标注「回封」；断板组 = 前一交易日涨停且最新交易日未涨停。
- 题材页前一交易日若该题材未进同花顺涨停前 20 名，改用东财涨停池按概念反推，并在单元格标注「东财口径」、弹层说明不含板块涨跌幅。

## 限制

- 同花顺未开放板块成分全量接口，题材弹层只能给出当日涨停成分股，不提供「全部 / 人气 / 中军」口径。
- 板块涨跌家数与资金流接口未开通，题材页以真实首板 / 连板结构替代；炸板池明细不可用，「回封」取自涨停池字段。
- 个股开高低收来自最新交易日快照：查看前一交易日涨停股时，价格类字段留空。
- 只覆盖交易日收盘后数据，盘中不更新。
- 页面状态（登录、收藏、笔记、标记）只存在当前会话，不落盘、不上传。
